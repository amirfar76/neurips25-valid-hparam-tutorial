# From Tuning to Guarantees: Statistically Valid Hyperparameter Selection

This repository contains tutorial notebooks accompanying a NeurIPS 2025 tutorial
on statistically valid hyperparameter selection using **Learn-Then-Test (LTT)**,
**Pareto Testing**, and **Quantile Learn-Then-Test (QLTT)**.

## Repository structure

```text
.
├── README.md
├── data/
│   ├── sample_LTT_losses.csv         # Generated by 01_LTT_risk_control.ipynb
│   ├── sample_PT_losses.csv          # Generated by 02_ParetoTesting.ipynb
│   └── sample_QLTT_losses.csv        # Generated by 03_QLTT_quantile_risk_control.ipynb
└── notebooks/
    ├── 01_LTT_risk_control.ipynb
    ├── 02_ParetoTesting.ipynb
    └── 03_QLTT_quantile_risk_control.ipynb
```

Each notebook is **self-contained**:

- It first **generates a synthetic CSV dataset** under `data/` to illustrate the
  expected format. The generated CSVs have **multiple loss values per hyperparameter**
  (one row per hyperparameter, many calibration losses as columns).
- Then it **loads that CSV** and runs the corresponding method.

## Data format

All CSV files share the same basic pattern:
- One row per hyperparameter configuration (indexed by a `lambda_id` column).
- Multiple columns of observed losses for each configuration.

### 1. `sample_LTT_losses.csv`

Used in `01_LTT_risk_control.ipynb`.

- Columns:
  - `lambda_id`: integer ID of the hyperparameter configuration.
  - `loss_1, loss_2, ..., loss_M`: M calibration losses for that configuration.

This is suitable for **single-objective** LTT risk control of the average loss.

### 2. `sample_PT_losses.csv`

Used in `02_ParetoTesting.ipynb`.

- Columns:
  - `lambda_id`: integer ID of the hyperparameter configuration.
  - `risk_1, ..., risk_M`: per-example values of a **risk to be controlled** (e.g., accuracy drop).
  - `cost_1, ..., cost_M`: per-example values of a **free objective** (e.g., cost / latency).

This is suitable for simple **two-objective** Pareto Testing:
- Control the average risk (e.g., accuracy reduction) at level `α` with probability `1-δ`.
- Among risk-controlling configurations, pick those with low average cost.

### 3. `sample_QLTT_losses.csv`

Used in `03_QLTT_quantile_risk_control.ipynb`.

- Columns:
  - `lambda_id`: integer ID of the hyperparameter configuration.
  - `loss_1, ..., loss_M`: per-episode losses for each configuration.

This is suitable for **quantile-based** LTT (QLTT), which controls a chosen
quantile (e.g., 0.1-quantile) of the loss distribution rather than just the mean.

## Getting started

1. Create and activate a Python environment (optional but recommended):

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # on Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Launch Jupyter and open the notebooks:

   ```bash
   cd notebooks
   jupyter notebook
   ```

3. Run each notebook from top to bottom. On first run, each notebook will:
   - Create the corresponding `sample_*.csv` file under `../data/` if it is missing.
   - Describe the CSV format in text and print a small preview.
   - Demonstrate the corresponding method (LTT, Pareto Testing, or QLTT) on the synthetic data.

## Requirements

The code targets a minimal scientific Python stack:

- Python ≥ 3.9
- numpy
- pandas
- matplotlib

All dependencies are listed in `requirements.txt`.
